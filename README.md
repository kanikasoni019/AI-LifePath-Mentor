# AI LifePath Mentor

🔗 Live Demo: https://ai-lifepath-mentor-8j8b.onrender.com/

AI LifePath Mentor is an AI-powered career and life guidance platform that provides personalized roadmaps, skill recommendations, and interactive mentoring to help users make smarter education and career decisions.

## 🚀 Features

- Personalized career roadmaps based on skills and goals
- AI chatbot mentor for real-time guidance
- Resume and job-path suggestions
- Interactive dashboard with progress tracking
- Step-by-step actionable learning plans

## 🛠 Tech Stack

**Frontend:** React (Vite), HTML, CSS, JavaScript  
**Backend:** Python (Flask)  
**AI/ML:** LLM APIs for intelligent mentoring  
**Deployment:** Vercel / Render
